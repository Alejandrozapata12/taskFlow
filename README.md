# TaskFlow

TaskFlow is a modern task management dashboard built with HTML5, CSS3, and Vanilla JavaScript.

The project focuses on creating a clean, responsive, and interactive productivity interface while applying modular JavaScript architecture and good frontend development practices.

## 🚀 Features

- Task management dashboard
- Create and manage tasks
- Task status organization
  - Pending
  - In progress
  - Completed
- Task priorities
  - High
  - Medium
  - Low
- Task categories/tags
- Due dates
- Comments counter
- Dashboard navigation
- Client-side routing
- Light and dark mode
- Persistent data using LocalStorage
- Login interface
- Login validation
- Toast notifications
- Password visibility toggle
- Remember-me interface
- Profile drawer
- Responsive design
- Modular JavaScript architecture

## 🛠️ Technologies

### Frontend

- HTML5

- JavaScript ES6+
